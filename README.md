# TMG Distribuidora de Águas e Bebidas

Site de uma página da TMG Distribuidora. O objetivo é gerar pedidos pelo WhatsApp.

- Para editar textos, telefone e fotos: veja [COMO-EDITAR.md](COMO-EDITAR.md).
- Publicação: Vercel, a partir da branch `main` (cada alteração na `main` vai ao ar sozinha).

## Para quem desenvolve

- Astro + Tailwind CSS, GSAP (ScrollTrigger e SplitText) e Lenis.
- Conteúdo: `src/data/site.json`. Componentes: `src/components/`. Scripts: `src/scripts/`.
- `npm install` e depois `npm run dev` (desenvolvimento) ou `npm run build` (gera a pasta `dist`).
